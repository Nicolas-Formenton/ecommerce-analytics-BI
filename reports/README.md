# Reports

This directory contains the generated PDF report from the Hex.tech Generative App.

## Chapters

1. Executive Summary
2. Models at a Glance
3. CLV
4. Order Value
5. Churn Risk
6. RFM Segmentation
7. Cohort Retention
8. 12-Month Forecast
9. What To Do About It

## Details

- **Format:** Dark mode, single page, clean chart labels
- **Generated via:** Playwright from the Hex app
- **Interactive Hex app:** [Análise Estatística](https://app.hex.tech/019eb393-3d2c-75b8-9208-12e174506253/app/Anlise-Estatstica-033WEl77K3vpzktpaYP4Ct/latest)

For running the analysis locally, use the Python scripts in `analysis/` directory.
